# MA 视频转序列图

将 mov、mp4、avi 等常用视频格式转换为 JPG 序列图。

## 功能

- 支持 mov, mp4, avi, mkv, wmv, flv, webm 等常用视频格式
- 可自定义 JPG 图片质量（1%-100%）
- 可设置输出序列图的起始帧号（默认从 $RFSTART 获取）
- 可自定义帧号位数（默认 4 位，如 cam.1001.jpg）
- 可自定义文件名前缀（默认 cam）
- 自动按照视频的 FPS 和分辨率输出序列
- 视频信息展示框：文件名、分辨率、FPS、总帧数、时长、编码器
- 输出路径默认：$HIP/images/{视频文件名}/
- 相机选择：支持从场景中选择相机，转换完成后自动设置相机的 Background Image 参数（vm_background）并禁用（vm_bgenable=0）

## 使用方式

1. 点击工具按钮打开窗口
2. 点击「浏览...」选择视频文件
3. 查看视频信息面板确认参数
4. 如需关联相机，在「相机」栏点击「选择...」选取场景中的相机
5. 调整 JPG 质量、起始帧号、帧号位数等参数
6. 点击「开始转换」

## 相机自动设置

若选择了相机，转换完成后会自动执行：
- 将相机的 vm_background 设为输出路径（如 $HIP/images/untitled/cam.$F4.jpg）
- 将相机的 vm_bgenable 设为 0（禁用状态）
- 路径从输出目录动态构建，与用户设置的输出位置一致

## 技术说明

- 使用 ffmpeg 单进程直接批量输出 JPEG 序列（解码 + 编码 + 写文件一步完成）
- 通过 -progress pipe:1 实时获取帧级进度
- ffprobe 优先获取元数据，ffmpeg 作为回退方案
- QThread 后台线程执行，支持取消操作
